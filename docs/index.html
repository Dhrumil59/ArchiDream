01 · The Problem

Marketing an unbuilt home sits on the critical path, and it is slow.

A developer cannot get construction finance until roughly 70% of units are pre-sold, and cannot pre-sell an apartment that does not exist yet without CGI, so the marketing visuals gate the whole project. Yet producing them, a studio modeling the building and rendering photoreal interiors, exteriors and a flythrough, takes weeks to months, with another round for every restyle. A 90-day delay adds roughly $1.1M in interest carry on a mid-sized project, and only 25% of developments hit their deadline (KPMG). Speed to market is not a nicety; it is margin.

02 · The Solution

One DXF in. Four ways to sell the space out.

Output

Styled top-down

A photoreal, furnished overhead in four interior styles - with clickable rooms placed pixel-perfect from the real geometry, not guessed from the image.

Output

Step-inside 360°

Click any room and enter an equirectangular panorama - generated on demand and grounded in that room's actual dimensions, doors, and windows.

Output

AI-directed tour film

One button: IBM Granite granite-4-h-small plans the shots, deterministic code renders a shareable marketing video from the plan and the room 360s.

Feature

Polygon region edit

Draw a freehand polygon over any part of a 360° panorama, describe the change - Qwen inpaints only that region. The rest of the image stays untouched.

03 · AI Approach & Architecture

Geometry is ground truth.
AI is the creative skin. The LLM decides · deterministic code executes

01

Extract

A deterministic engine parses the DXF into a semantic model - rooms, walls, openings, in real meters. No AI touches the measurements.

ezdxf · matplotlib
02

Anchor

Render to an exact meters→pixel plan, giving pixel-perfect clickable room hotspots over whatever gets generated on top.

SVG polygons
03

Dress

Image AI stylizes the plan and paints each 360 - camera-locked and fact-grounded, so it decorates without inventing architecture.

Gemini 3 Pro Image · Qwen
04

Direct

A single IBM Granite call returns a shot-plan; a deterministic compiler renders the tour film frame-accurately.

IBM Granite 4-h-small (watsonx) · HyperFrames
+ Polygon region edit Qwen wanx2.1-imageedit

In edit mode, the pano renders flat. The user draws a closed polygon, types a prompt, and Qwen inpaints that exact masked region - crop → edit → feathered paste back → sphere reloads.

04 · How IBM Bob Was Used

IBM Bob was the primary development tool - the AI dev assistant that built ArchiDream through spec-driven development.

The workflow mirrors the product itself: plan deliberately, then let deterministic code execute - AI as a partner throughout, not a black-box generator.

Ask

Explore an unfamiliar CAD/DXF codebase and its data model before extending it.

Plan

Generate an implementation plan per feature - the hotspot transform, the fact-grounded prompts, the video pipeline - reviewed and refined first.

Code

Build feature by feature across backend, UI, and prompts - with tight "check for bugs" review-and-fix loops after each phase.
